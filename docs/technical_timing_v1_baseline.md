## 一、策略概述

**策略名称**：技术面择时策略（Technical Timing Strategy）

**核心逻辑**：ML多因子选股 + 技术面择时（金叉买入/死叉止损卖出）

**策略定位**：股票短线策略，T+1成交，信号驱动调仓（不固定调仓频率）

---

## 二、完整实现逻辑

### 2.1 候选池生成（ML多因子选股）

**模型**：LightGBM（LGBM）
- 特征数：31个
- 训练标签：forward_3（未来3天收益率）
- 模型文件：`artifacts/stock-ml/stock-wf-model.txt`

**特征构成**：
| 类别 | 数量 | 示例因子 |
|---|---|---|
| 基础量价因子 | 19个 | momentum20、trend、drawdown60、volumeRatio、volatility20、peTtm、pb、roe、mktCap等 |
| 行业轮动因子 | 10个 | industry_mom20、industry_rank20、industry_excess5、industry_excess20、industry_amount_chg等 |
| 资金流向替代因子 | 2个 | turnover_surge、close_position_5d |

**选股流程**：
1. 每个交易日，用训练好的模型对全市场股票打分
2. 按得分从高到低排序，选 **Top20** 作为候选池
3. 股票池过滤：
   - 排除北交所（920开头）
   - 排除科创板（688开头）
   - 最小市值20亿（mktCap单位是万元，20亿=200000万元）

### 2.2 买入信号（必须同时满足）

| 条件 | 计算方式 | 作用 |
|---|---|---|
| **金叉** | 前一日MA5 ≤ MA10，当日MA5 > MA10 | 捕捉短期趋势启动点 |
| **趋势向上** | 当日收盘价 > MA20 | 确保在中期趋势之上，不抄底 |

**金叉计算公式**：
```
ma5_today = 最近5日收盘价均值
ma10_today = 最近10日收盘价均值
ma5_yesterday = 前一日MA5
ma10_yesterday = 前一日MA10
golden_cross = (ma5_yesterday <= ma10_yesterday) AND (ma5_today > ma10_today)
```

### 2.3 卖出信号（满足任一即可）

| 信号 | 计算方式 | 作用 |
|---|---|---|
| **死叉** | 前一日MA5 ≥ MA10，当日MA5 < MA10 | 趋势反转，止盈离场 |
| **止损** | 当前价 < 买入价 × (1 - 5%) | 控制单笔亏损，避免深套 |

### 2.4 仓位管理

| 参数 | 值 | 说明 |
|---|---|---|
| 最大持仓数 | 5只 | 分散风险 |
| 仓位分配 | 等权 | 每只股票分配相同资金 |
| 单只目标仓位 | 总资金 / 5 | 每次买入按目标仓位计算 |
| 买入单位 | 100股（1手） | A股最小交易单位 |

**等权分配计算**：
```
目标仓位 = (现金 + 持仓市值) / 5
买入股数 = int(目标仓位 / 买入价 / 100) * 100
```

### 2.5 交易成本

| 成本项 | 费率 | 说明 |
|---|---|---|
| 佣金 | 万3（0.03%） | 买卖都收 |
| 印花税 | 千0.5（0.05%） | 仅卖出收 |
| 滑点 | 0.1% | 回测中模拟实际成交价格偏差 |

**成交方式**：
- 回测：当日收盘价 × (1±滑点)
- 模拟盘/实盘：T+1开盘价（杜绝未来函数）

## 七、已知问题与优化方向

### 7.1 已知问题（按严重程度排序）

| 优先级 | 问题 | 影响 |
|---|---|---|
| P0 | 候选池太窄（仅Top20） | 漏掉很多技术面机会 |
| P0 | 无熊市空仓机制 | 最大回撤-41.2%偏大 |
| P1 | 金叉条件太严格 | 抓不到趋势延续阶段的强势股 |
| P1 | 只有固定止损，无移动止损 | 利润保护不足 |
| P1 | 买入不考虑成交量 | 可能买入缩量假金叉 |
| P1 | 无行业分散机制 | 行业集中度风险 |
| P2 | 信号太少，频繁空仓 | 资金利用率低 |
| P2 | 回测期较短（14个月） | 长期稳定性未知 |
| P2 | 前端未接入展示 | 用户无法在Web查看 |

### 7.2 已验证无效的优化方向

| 优化方向 | 回测结果 | 结论 |
|---|---|---|
| 增加"放量突破"买入条件 | 总收益从+431.5%降至+9.03% | ❌ 不采用，放量突破是追高信号 |
| 增加"放量滞涨"卖出条件 | 总收益从+431.5%降至+84.04% | ❌ 不采用，放量滞涨不一定是见顶 |

### 7.3 待验证的优化方向

| 优化方向 | 预期改善 |
|---|---|
| 扩大候选池（Top20→Top100） | 抓到更多机会 |
| 增加熊市空仓（沪深300<MA20空仓） | 降低回撤 |
| 增加移动止损（盈利后止损线上移） | 保护利润 |
| 买入时考虑成交量（放量金叉优先） | 提高胜率 |
| 行业分散（单行业不超过2只） | 降低行业风险 |

## 十、注意事项

1. **本文件是V1基线的完整记录**，后续优化版本应以此为基准对比，不要覆盖本文件
2. **回测结果不代表未来收益**，实盘表现可能与回测有差异
3. **模拟盘刚启动**，实盘验证不足，建议观察至少1个月再考虑实盘
4. **mktCap单位是万元**，配置minMktCap=200000对应20亿，不要写成2000000000
5. **index_daily_bars表列名是ts_code不是code**，查询沪深300用`WHERE ts_code="000300.SH"`
6. **ml_walkforward模型weights为空是正常的**（ML模型不需要加权因子），common.py的load_config已跳过空权重模型
